# Agent release approval ledger
No approvals are inferred from file names, a generated WAV, or a CC0 source alone. Every entry in agent-approvals.json is keyed by existing sound ID and bound to the full generated WAV SHA-256. A maintainer must provide license, rightsEvidence (including source and redistribution basis), reviewEvidence (human reviewer/date/listening notes), events, tags, family, repeatSafe. Allowed licenses are CC0-1.0, MIT, or LicenseRef-Verdant with explicit ownership/permission evidence. Unknown or personal-use assets must not be approved. Changing bytes requires new review. Empty ledger intentionally produces awaiting-review, not a published sound release. Existing human-facing catalog is not a source of authority for agent distribution. Historical raw files and public deployments require separate rights remediation. Do not fake approvals to make the count look good.
